Where Opal is better: exactly

  • The only free tool here that signs with a plugged-in DSC USB token (PKCS#11). The private key never leaves the token, and signatures verify fully offline. Live-proven on an e-Mudhra HYP2003.
  • Acrobat Pro standards at zero cost: Commercial print preflight with PDF/X fixups, PDF Portfolios (ISO 32000-1 collections), DocMDP certification locks (P=1, P=2, P=3), and Long-Term Validation (LTV / DSS) embedding.
  • Zero-upload is architecture, not a promise: single local app, MIT-licensed source. Read the code and see that nothing phones home. Web tools process your document on their servers.
  • Built for the Indian counter: Aadhaar/passport ID photo 413×599, stamp photo, 4R/5R/6R print at 300 DPI, WhatsApp PDF under 1 MB, WhatsApp-ready photos: one click each, ~1 s per job.
  • The wheel: hold Shift/Alt/Ctrl while dragging a file: 103 actions appear around your cursor. Plus watch-folder auto-convert, right-click menu, conversion history, and a CLI (--sign/--verify-signature included).
  • Offline AI in the Full build: background removal and 2x/4x upscale run with the network unplugged.

Where Opal is not better yet: honestly

  • Brand and polish: Acrobat, Foxit, and PDFgear have years of UI polish, mobile apps, and dedicated support teams. Opal is a focused open-source project.
  • Features Acrobat Pro still owns: Complex JavaScript form scripting automation, optical text reflow inside scans, and Adobe Cloud team collaboration.
  • Distribution: published zips are Windows-only right now (macOS/Linux build from source, CI green on all three) and the exe is not code-signed yet. Windows SmartScreen will warn until we sign it.
  • No Android/iOS app (Xodo and PDFgear have them). A Flutter port is possible for conversions and .pfx signing, but USB DSC tokens do not exist on Android. The headline feature is desktop-only.

Verdict: If your job is signing PDFs with a real DSC USB token at a counter, certifying legal documents with DocMDP permissions, auditing print preflight for PDF/X, or packing executive PDF Portfolios... Opal does all of it offline for free. If you need Adobe Cloud team collaboration or complex JavaScript form scripting, paid Acrobat Pro is still the tool. We would rather tell you that than pretend.
